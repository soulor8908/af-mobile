## 1. 产品定位与导航结构

**一句话**：自然语言（NLI）驱动的个人财务管理助手——记账、多账户、负债追踪、分期、日历、统计、私有化数据。

**底部 6 Tab 导航**（对应 aiflow `af-tabbar` + `route`，keepAlive 保留）：

| key | 路径 | 页面 | 说明 |
|---|---|---|---|
| chat | `/` | 对话（首页） | 总览 + 近期流水 + 全屏聊天入口 |
| accounts | `/accounts` | 账户 | 账户列表 + 左滑编辑/删除 + 添加表单 |
| calendar | `/calendar` | 日历 | 月视图 + 每日收支/待还点 + 日详情 + 本月待还 |
| txs | `/transactions` | 流水 | 列表 + 筛选 + 增删改（默认本月） |
| stats | `/stats` | 统计 | 统计卡 + 环比/同比 + 走势图 + 分类 + 异常 + 资产负债 |
| settings | `/settings` | 设置 | AI 配置 + Agent + 记忆 + 分期/周期 + 数据管理 + 保险库 |

> 加载流：未启用加密保险库时直接进入 shell；启用时先进入 Lock 页（见 §6），解锁后注入加密持久化并进入 shell。

## 2. 页面功能规格

### P1 对话页（chat，`/`）

**首页区域（shell 内）**
- 顶部分两个总览格：总资产 / 总负债（点击打开资产或负债明细弹层）。
- 中间「近期流水」：最近 5 条排序流水，空态提示。
- 底部固定「聊天输入入口」按钮（tab-bar 上方），点击打开全屏聊天弹层。

**全屏聊天弹层（af-dialog variant=bottom 命令式）**
- 顶栏：会话列表（menu 图标，展开/收起）+ Agent 切换 pill + 会话标题 + 新建会话（plus）+ 关闭。
- 试用提示横幅（仅内置配置时）：提示剩余次数，点击跳设置页 AI 配置区。
- 消息流：user/ai 气泡；ai 气泡含 thinking / tool / ok / error / clarify / streaming 多态；流式光标；options 快捷按钮。
- 底栏：快捷输入（可展开选择/管理）+ textarea（Enter 发送 / Shift+Enter 换行 / 自适应高度）+ 发送按钮。
- 会话管理：新建、切换、删除（confirm 确认）。
- Agent 切换：agents 列表选择，切换后 toast。
- 还款日主动提示：进入聊天时若今日有到期贷款且未还款，自动追加 AI 提示气泡 + 付款账户 options（含「暂不记录」），点击触发还款流水。

**数据流**
- 输入 text → 本地引擎 `engine.handle` 或 AI `chatWithAI`（SSE 流式 + 工具调用）。
- 纯本地模式（无 Key 无代理）：确定性引擎，支持 clarify（确认/取消 options）。
- AI 模式：thinking → tool → streaming 气泡推进 → 落库 + 自动习惯提取。
- AI 失败自动回退本地引擎。

### P2 账户页（accounts，`/accounts`）

- 账户列表（`af-list` + `af-swipe-cell`）：非编辑态卡片显示名称/类型 tag/账户 meta（额度·账单日·还款日 / 总限额 / 月供·利率·下期）/余额（负债类负号）。
- 左滑操作：编辑 / 删除。删除有历史流水时改为「注销」二次确认。
- 行内编辑态：按账户类型动态渲染字段（去编辑）。
- 已停用账户折叠区（`<details>`）。
- 添加账户表单：账户名 + 类型 + 按类型动态字段（余额 / 额度 / 账单日·还款日·是否次月 / 贷款本金·年利率·期数·放款日·还款方式·每月还款日）+ 校验错误展示。

### P3 日历页（calendar，`/calendar`）

- 月视图 grid（自建，G2-B）：首栏 一~日；月份切换（‹ › 按钮 + 横滑手势）；今日高亮；每日收支（支出-/收入+）/待还点（dots）；选中日深色。
- 月度汇总：本月待还；当月额外显示当月收入、当月结余。
- 日详情（选中日展开）：当日待还列表（含逾期标记）+ 当日流水列表。
- 本月待还列表：日期 + 名称 + 金额 + 逾期 tag。

### P4 流水页（txs，`/transactions`）

- 筛选：月份（默认本月，可清除）+ 类型 + 支付方式（更多筛选折叠）。
- 「+ 记一笔」新增表单：类型/金额/日期/支付账户/转入账户（转账）/还款账户（还款）/分类/描述；切换类型重置对手方。
- 列表（`af-list` + `af-swipe-cell`）：描述/类型/账户/估算 tag/金额（收入/退款 +，转账 ↔，其余 -）。
- 左滑：编辑（可编辑条件：主/对手账户非贷款非注销）/ 删除。
- 行内编辑态：描述/金额/日期/分类/支付账户/对手账户。
- 校验：金额>0、日期必填、账户必选、转账/还款对手必填且不同；超额/余额不足直接失败；大额（≥50000）二次确认。
- 底部：共 N 笔。

### P5 统计页（stats，`/stats`）

- 月份筛选。
- 4 统计卡：支出/收入/结余/笔数。
- 4 环比同比卡：支出环比/支出同比/收入环比/预计全月。
- 支出走势图（SVG，G3）：本月/上月累计曲线 + 上月合计参考线 + 预计全月点。
- 导出：月度报表 CSV / 趋势图 PNG。
- 分类涨跌（对比上月）：topRisers / topFallers。
- 异常提醒：高额/偏高/创新高列表。
- 分类支出：分类 + 横向占比条 + 金额。
- 资产负债：总资产/总负债/净资产。

### P6 设置页（settings，`/settings`）

- **AI 助手配置**（`#ai-config-section`，供首页跳转滚动定位）：服务商 select（含自定义）+ API Key(password) + Base URL + 模型（select 或输入）；保存/测试连接/清除配置；未启用保险库时明文警告。
- **Agent 人设**：列表（预置 tag / 已禁用 tag）+ 预置可 启用/禁用，自定义可 编辑/删除；新建 Agent（名称/描述/系统提示词三段 prompt）。
- **AI 记忆**：添加（内容+类型 select）；列表（类型 tag + 自动 tag + 内容）左滑编辑/删除；清空全部。
- **分期计划**：只读列表（名称 + 期数 + 每期 + 下期/状态）。
- **周期记账规则**：只读列表（描述 + 每月几号 + 金额 + 生效态）。
- **数据管理**：导出 JSON / 导入备份（文件）/ 导出加密备份(.abak，设口令) / 导入加密备份（口令）/ 清空聊天记录 / 清空全部数据；busy 态禁用全部按钮。
- **加密保险库**（启用时）：立即锁定。

### P7 锁页（Lock，`/` 前）

- 模式：setup（启用加密）/ unlock（解锁）/ resetAnswer / resetRecovery / disable（关闭加密）。
- setup：密码/确认密码（≥8 位含字母数字）/安全问题/答案；成功展示一次性恢复码。
- unlock：密码 + 「忘记密码」入口。
- resetAnswer / resetRecovery：答案或恢复码 + 新密码。
- disable：当前密码 → 恢复明文并回退钩子。
- 解锁成功：注入 store/chat/memory 三路加密持久化钩子 → 加载 state → hydrate AI 配置/聊天/记忆 → 进入 shell。

## 3. 弹层与命令式流程

| 场景 | 原实现 | aiflow | 说明 |
|---|---|---|---|
| 确认框 | `dialog.confirm` | `af-dialog` 命令式 helper | G4：body slot 放按钮，返回 Promise<boolean> |
| 输入框 | `dialog.prompt` | `af-dialog` + `af-field` | G4：body slot 放表单，返回 Promise<string\|null> |
| 提示框 | `dialog.alert` | `af-dialog` | 单按钮 |
| 轻提示 | `dialog.toast` | `af-toast` 单例 | 自动消失 |
| 全屏聊天 | `FullscreenModal`(Portal) | `af-dialog` variant=bottom | 命令式 + 自定义气泡 |
| 资产/负债明细 | 内联 modal | `af-dialog` | 列表展示 |
| 快捷输入管理 | 内联 modal | `af-dialog` | 增删改 + 恢复默认 |

## 4. 加载 / 空 / 错误 / 无障碍

- **加载态**：`af-skeleton-page` / `.skeleton-line`；数据 busy 用 `aria-busy`；AI 测试连接 `testing` 态。
- **空态**：`.empty` 文案（账户/流水/记忆/会话/待还/分类/走势）。
- **错误态**：表单 `error-text`；异步 toast；`aria-live="polite"` 覆盖加载/错误/结果区。
- **无障碍**：左滑操作按钮可聚焦（键盘可达）；弹层焦点陷阱 + 还原；`prefers-reduced-motion`；图标默认 `aria-hidden`，可交互图标带 `aria-label`；列表 `aria-current` 标记活跃 tab。

## 5. 边界与异常（需求基线节选）

- 金额：口语化金额解析（`3k`/`两千五`/`三十五块五`/估算标记）；手动录入必须 >0。
- 账户：负债类型（credit/loan/installment）余额语义为「已用/剩余本金」，显示负号；贷款流水系统自动生成，不可手动新增/编辑。
- 删除约束：有历史流水账户不可删 → 归档（注销，余额归零、不参与统计）。
- 大额：单笔 ≥50000 二次确认。
- 重复检测：`applyTransaction` 返回 warnings（UI 展示）。
- 还款日：前 3 天/当天主动提示；今日已还款去重；同会话语义内 `promptedLoanIds` 去重。
- 数据安全：核心金融状态由前端维护，AI 仅生成指令（不持有状态）；加密 vault AES-GCM 256。
- 离线容错：AI 失败回退本地确定性引擎，仍可记账。
