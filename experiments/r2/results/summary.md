## 备注

- **幻觉 API 明细**：无。条件 B 全部 import 来自 `./k-flow.js`，仅用词表内 API（html/signal/computed/render/Show/For）；无 createSignal/createEffect/.value/on:click/use:/class:/style:/ref=/reactive/watch/onMounted/innerHTML 等词表外框架级 API。
- **回避任务明细**：无。条件 B 的列表（For）、条件渲染（Show）、派生（computed）均用 k 词表实现，未绕回原生 DOM 手写。
- **异常情况（采集 2）**：条件 A 首轮 5 任务全 FAIL（子 agent 未创建 DOM 结构，直接 querySelector 返回 null）；返工 1 轮后补上 `el.innerHTML = ...` 全过。条件 B 无此问题（render() 自动创建 DOM）。
- **与 B3 差异**：B3（GLM-5.3）中 t4 需 1 次返工（2 轮通过），采集 2（Qwen 3.7 Plus）条件 A 返工 1 轮、条件 B 零返工；会话成本比 78.9% 略高于 B3 的 75.8%，但仍 < 85% 阈值。三次采集为不同模型家族，B/A 为相对比值（消掉分词器/啰嗦差异），可跨模型对比；绝对 token 数不可比。

## 判定

已回收 3 个模型家族（GLM-5.3 + DeepSeek V4 Flash + Qwen 3.7 Plus），B/A 会话成本比 75.8% / 81.2% / 78.9% 均 ≤ 85%，一次通过率差 0pp ≤ 10pp，幻觉/回避任务均为 0 → **H2 成立（3/4 家族口径）**。
按任务书要求 ≥4 个异构家族，仍需外部实测 1 个异构家族（建议 Claude 或 Gemini），按 README 第五节流程执行。
