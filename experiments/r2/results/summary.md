## 备注（幻觉 API 明细、回避任务明细、异常情况）

### GLM-5.3（2026-08-26，调度式子代理采集）

- **采集方式**：主代理（GLM-5.3，已深度接触 k 源码，不可作被试）派两个零上下文子代理分别作 A/B 臂被试；子代理提示词仅内联词表卡 + 任务卡原文 + 禁用工具（防其检索仓库破坏闭卷条件）。k 不在 GLM-5.3 训练分布（私有仓库、晚于训练截止），子代理不继承主代理对话上下文，被试合法性成立。
- **A 臂 t5 失败明细（返工 1 轮修复）**：① `computed` 使用了但未 import（`computed is not defined`）；② 用 `hidden` 属性隐藏 #err，但 textContent 仍含"邮箱格式错误"，违反任务卡"#err 隐藏时无此文本"约束。返工轮两处一并修复（补 import + `textContent` 置空替代 `hidden`）。
- **协议偏差（后续采集须避免）**：返工提示中除评分器输出原文外附加了断言通过标准说明（原协议仅贴评分器输出 + 一句话），可能省去 1 轮返工。
- **B 臂行为记录**：子代理把 signal 对象直接用作子位插值（`${n}`）与 `For({ each: items })` 的 each 实参——signal 本身是函数，属词表卡"传函数（signal/getter）"的合法形态，**非幻觉**；t2 主动传 `key: 'id'`（与 k-for-require-key lint 建议一致）。零幻觉、零回避。
- **会话 tokens 无法采集**：子代理无 usage 统计，同 baseline 记"—"。代码 token：A 1251 / B 921（tokens.mjs），B/A = 73.6%，低于 B3 的 76.9%（词表卡 token 560/445 与 B3 一致）。
