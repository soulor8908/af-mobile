## 备注

- **幻觉 API 明细**：无。条件 B 全部 import 来自 `./k-flow.js`，仅用词表内 API（html/signal/computed/render/Show/For/Switch）；无 createSignal/createEffect/.value/on:click/use:/class:/style:/ref=/reactive/watch/onMounted/innerHTML 等词表外框架级 API。
- **回避任务明细**：无。条件 B 的列表（For）、条件渲染（Show）、多路分支（Switch）、派生（computed）均用 k 词表实现，未绕回原生 DOM 手写。
- **异常情况**：无。两条件均一次通过（0 返工），评分器 28/28 断言全过。
- **与 B3 差异**：B3 中 t4 需 1 次返工（2 轮通过），本次两条件均一次通过；会话成本比 81.2% 略高于 B3 的 75.8%，但仍 < 85% 阈值。

## 判定
