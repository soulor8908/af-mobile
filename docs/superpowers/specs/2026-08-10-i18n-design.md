# i18n 国际化功能设计

> 版本：v1.6.0
> 日期：2026-08-10
> 范围：库内置文本国际化 + `t()` 翻译函数（含占位符替换）

---

## 1. 目标与范围

### 目标

为 af-mobile 库提供轻量国际化能力：
- 库内 33 处硬编码文本（aria-label / placeholder / 空态文案 / 加载提示等）支持 zh-CN / en-US 切换
- 提供 `t()` 翻译函数供消费端使用，支持 `{name}` 占位符替换
- 语言切换后已挂载组件自动更新文本，无需重建 DOM

### 非目标（YAGNI）

- ❌ 复数支持（消费端可写两个 key 或用 `Intl.PluralRules`）
- ❌ ICU MessageFormat 语法（解析器 >1KB，超预算）
- ❌ 内置 `Intl.NumberFormat` / `Intl.DateTimeFormat` 格式化（消费端自行调用原生 Intl）
- ❌ 懒加载语言包（库仅内置 2 语言，体积极小）
- ❌ 嵌套 key 对象（用扁平 key 节省体积）

## 2. 架构

### 模块结构

```
src/lib/i18n.js        ← 新增（核心 API + zh-CN/en-US 字典，~1.1KB gzip）
src/lib/af-element.js  ← 修改（+20 行 _applyI18n + onLocaleChange 默认实现 + connectedCallback 调用）
src/index.js           ← 修改（导出 i18n API）
src/index.d.ts         ← 修改（类型声明）
scripts/size-check.mjs ← 修改（coreRuntime 预算 3.7→5.2KB）
```

### 数据流

```
setLocale('en-US')
  │
  ├─→ localStorage.setItem('locale', 'en-US')
  ├─→ document.documentElement.lang = 'en-US'
  └─→ documentElement.dispatchEvent(CustomEvent('localechange', {detail: 'en-US'}))
        │
        ▼
  AfElement.connectedCallback 中订阅（与 themechange 完全对称）
        │
        ▼
  this.onLocaleChange() → this._applyI18n()
        │
        ▼
  遍历 static i18n 映射表，对每个选择器：
    - 静态形式：el.setAttribute(attr, host[prop] != null ? host[prop] : t(key))
    - 动态形式：el.setAttribute(attr, fn(host, t, el, index))
```

### SSR 安全

- 模块顶层无 DOM/localStorage/navigator 访问
- 所有副作用在函数内惰性执行，带 `typeof` 守卫
- 与 `theme.js` 模式完全对称，Node 环境 `import` 不抛错

## 3. API

### 函数签名

```ts
// 翻译
t(key: string, vars?: Record<string, string|number>): string

// 语言管理
getLocale(): string                        // 当前语言，默认 'zh-CN'
setLocale(locale: string): void            // 设置 + 持久化 + dispatch 'localechange'
initLocale(): void                         // 从 localStorage 恢复（入口尽早调用）
addMessages(locale: string, dict: Record<string, string>): void  // 注册/覆盖语言包

// 字典导出（供组件直接访问）
messages: Record<string, Record<string, string>>
```

### t() 实现要点

- **回退链**：`当前 locale → zh-CN → key 自身`（不抛异常）
- **占位符**：`/\{(\w+)\}/g` 单次正则 callback 替换
- **未声明占位符保留原样**：`{x}` 未传 vars 时保留 `{x}`（开发可见错误）
- **vars 用 `in` 检查**：允许 `0` / `false` / 空串
- **性能优化**：无 vars 时跳过 replace

### setLocale 实现

```js
export function setLocale(locale) {
  if (_locale === locale) return;
  _locale = locale;
  if (typeof localStorage !== 'undefined') localStorage.setItem('locale', locale);
  if (typeof document !== 'undefined') {
    document.documentElement.lang = locale;
    document.documentElement.dispatchEvent(new CustomEvent('localechange', { detail: locale }));
  }
}
```

### initLocale 实现

```js
export function initLocale() {
  if (typeof localStorage === 'undefined') return;
  const saved = localStorage.getItem('locale');
  if (saved && MESSAGES[saved]) {
    _locale = saved;
    if (typeof document !== 'undefined') document.documentElement.lang = saved;
  } else if (typeof navigator !== 'undefined') {
    const nav = navigator.language || '';
    const matched = Object.keys(MESSAGES).find(k => k === nav || k.startsWith(nav.split('-')[0]));
    if (matched) _locale = matched;
  }
}
```

## 5. 基类改造：static i18n 映射表

### 映射表格式

```js
static i18n = {
  [selector]: [attr, keyOrFn, fallbackProp?, skipIfAttr?],
};
```

- `selector`：CSS 选择器；`'@'` 表示 host 自身（`:host` 在 querySelector 不工作）
- `attr`：属性名；空串 `''` 表示 `textContent`
- `keyOrFn`：i18n key（字符串）或函数 `(host, t, el, index) => string`
- `fallbackProp`（可选，仅静态形式）：`host[prop] != null` 时优先用 `host[prop]`
- `skipIfAttr`（可选，仅静态形式）：host 有该属性时跳过

### 基类实现

```js
// af-element.js 新增
import { t as _t } from './i18n.js';

_applyI18n() {
  const map = this.constructor.i18n;
  if (!map) return;
  for (const sel in map) {
    const [attr, keyOrFn, fallback, skipIf] = map[sel];

    // @ 表示 host 自身
    if (sel === '@') {
      if (skipIf && this.hasAttribute(skipIf)) continue;
      const val = typeof keyOrFn === 'function'
        ? keyOrFn(this, _t, this, 0)
        : (fallback && this[fallback] != null ? this[fallback] : _t(keyOrFn));
      if (attr) this.setAttribute(attr, val);
      else this.textContent = val;
      continue;
    }

    // 普通选择器：querySelectorAll 支持循环场景（picker columns / swiper dots）
    const els = this.$root.querySelectorAll(sel);
    els.forEach((el, i) => {
      const val = typeof keyOrFn === 'function'
        ? keyOrFn(this, _t, el, i)
        : (fallback && this[fallback] != null ? this[fallback] : _t(keyOrFn));
      if (attr) el.setAttribute(attr, val);
      else el.textContent = val;
    });
  }
}

onLocaleChange() { this._applyI18n(); }

connectedCallback() {
  // ...现有代码...
  this.mounted?.();
  this._applyI18n();
}
```

### localechange 订阅（与 themechange 对称）

```js
connectedCallback() {
  if (this._mounted) return;
  this._mounted = true;
  if (this.onThemeChange) {
    this._themeHandler = (e) => this.onThemeChange(e.detail);
    document.documentElement.addEventListener('themechange', this._themeHandler);
  }
  // 新增：localechange 订阅
  if (this.onLocaleChange) {
    this._localeHandler = (e) => this.onLocaleChange(e.detail);
    document.documentElement.addEventListener('localechange', this._localeHandler);
  }
  this.mounted?.();
  this._applyI18n();
}

disconnectedCallback() {
  if (this._themeHandler) {
    document.documentElement.removeEventListener('themechange', this._themeHandler);
    this._themeHandler = null;
  }
  // 新增：清理 localechange 监听
  if (this._localeHandler) {
    document.documentElement.removeEventListener('localechange', this._localeHandler);
    this._localeHandler = null;
  }
  this.unmounted?.();
  this._mounted = false;
}
```

## 7. 体积预算

| 部分 | 体积估算 |
|---|---|
| i18n.js（字典 + API） | ~1.1KB gzip |
| 基类 `_applyI18n` + `onLocaleChange` + 订阅/清理 | ~250 字节 |
| 16 组件映射表 + 2 处事件回调 t() | ~700 字节 |

### size-check.mjs 预算调整

- `coreRuntime`: 3.7KB → 5.7KB（i18n 1.1KB + 容差 0.9KB）
- i18n 与 router/state/fetch 同属"核心运行时按需 import"，不计入 `total`（20 组件 + 基类）
- 基类 `base` 预算：1.2KB → 1.5KB（+`_applyI18n` + 订阅/清理）
- 单组件 `perComponent` 预算：2.6KB → 2.8KB（+映射表）
- `total` 预算：19.5KB → 20.5KB（含基类增量 + 映射表）

## 9. 业界对比

| 维度 | @shoelace-style/localize | @nanostores/i18n | nano-i18n | 本方案 |
|---|---|---|---|---|
| 体积 | ~2KB | ~2.5KB | ~0.5KB | ~2.0KB |
| 占位符 | 函数式 | `{name}` 多次 replace | `{}` 位置 | `{name}` 单次正则 |
| 回退链 | region→lang→fallback→key | 当前→base | 无 | 当前→zh-CN→key |
| 切换通知 | MutationObserver lang | atom subscribe | 无 | CustomEvent |
| 框架依赖 | Lit | nanostores | 无 | 无 |
| 声明式绑定 | ❌ | ❌ | ❌ | ✅ static i18n 映射表 |

### 关键差异化

1. **static i18n 映射表**：业界无此方案，适合"零框架 Web Components"场景
2. **单次正则占位符**：比 nanostores 多次 replace 性能更优
3. **不内置 Intl**：YAGNI，消费端自行 `Intl.NumberFormat`
4. **CustomEvent 而非 MutationObserver**：与 theme.js 对称，省 ~200 字节

## 10. 改造原则

1. **不重建 DOM**：`_applyI18n` 只 `setAttribute` / `textContent`，避免 popover/dialog 状态丢失
2. **不重新绑定事件**：只动文本，事件监听保持不变
3. **属性优先**：用户显式属性 > 字典回退
4. **模板纯净**：HTML 里零 i18n 痕迹，所有逻辑在 `static i18n` 映射表
5. **集中声明**：50 个点 = 50 行映射表，一处看全
6. **最小更新**：基类只 `setAttribute`/`textContent`，不重建 DOM，不丢状态
