# 文档站 P1 实施计划（站点骨架 + Guide + 部署流水线）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `@af-mobile/ui` 文档站能在 GitHub Pages（`/v/` base）上线可访问，含 VitePress 站点骨架、4 篇 guide、demo 产物集成和自动部署流水线。

**Tech Stack:** VitePress、Vite（已有 `@vitejs`）、Node 20+、GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-08-17-docs-site-design.md`

---
**仓库 / 路径约定**

### Task 8: GitHub Pages 部署流水线

**Files:**
- Create: `.github/workflows/docs.yml`

- [ ] **Step 1: 写 workflow**

创建 `.github/workflows/docs.yml`：

```yaml
name: docs

on:
  push:
    branches: [main]
    paths:
      - 'site/**'
      - 'demo/**'
      - 'src/**'
      - 'scripts/**'
      - 'package.json'
      - 'vite.config.js'

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - run: npm run demo:build
      - run: mkdir -p site/public/demo && cp -r demo-dist/* site/public/demo/
      - run: npm run docs:build
      - uses: actions/configure-pages@v5
        with:
          static_site_generator: vitepress
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site/.vitepress/dist
      - uses: actions/deploy-pages@v4

  # 说明：需在 GitHub 仓库启用 Pages → 从 GitHub Actions 部署;
  # 仓库名 af-mobile-docs，site 访问路径为 <user>.github.io/af-mobile-docs/v/。
```

- [ ] **Step 2: YAML 语法校验**

Run: `npx --yes yaml-lint .github/workflows/docs.yml`
Expected: 输出 `0 problems` 之类无错误结果。

- [ ] **Step 3: Commit**

```bash

git commit -m "ci(docs): deploy vitepress site to github pages"
```
